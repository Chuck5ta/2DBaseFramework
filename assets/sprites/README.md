# Sprites

Pixel-art sprite sheets made for this framework's demo. Like the other demo assets they
are released under **CC0** (public domain): use them for anything.

| File | What it is |
|---|---|
| `slime.png` + `slime.json` | The player: 14 frames of 32×32 in Aseprite's sprite-sheet format, with the tags **idle** (4 frames, loops), **hop** (6 frames, loops) and **burst** (4 frames, plays once) |
| `coin.png` | A spinning coin: 8 frames of 16×16 in a row |

To edit the slime in [Aseprite](https://www.aseprite.org/), use *File → Import Sprite
Sheet* (32×32 frames), then re-export with *File → Export Sprite Sheet*: output *JSON
Data* as *Array*, with *Tags* ticked and *Trim* unticked, next to the PNG.
